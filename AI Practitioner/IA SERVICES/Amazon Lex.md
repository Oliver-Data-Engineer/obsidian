## O que é o Amazon Lex?

Equipado com a mesma tecnologia da Alexa, o Amazon Lex é um criador de bate-papo com inteligência artificial que permite aos usuários interagir com qualquer aplicação usando voz ou bate-papo em linguagem natural. Use o Amazon Lex para criar e implantar interfaces de IA conversacionais para qualquer aplicação. A integração do bate-papo com IA aos processos de negócios e casos de uso existentes oferece aos usuários mais flexibilidade e suporte para realizar o trabalho de maneira natural para seus usuários. As experiências de chat com IA em aplicações voltadas para o cliente aumentam a satisfação do cliente.

### O que é uma interface de chat com IA?

Uma interface de chat com IA permite que os usuários interajam com suas aplicações por meio de linguagem natural e conversas produzidas com IA generativa. Por exemplo, se você tiver uma aplicação de reserva de voos, seus usuários podem solicitar detalhes do voo à interface de chat com IA, fazer uma reserva, solicitar alterações e muito mais. Esse recurso permite que os usuários interajam com a aplicação de forma mais intuitiva e tenham mais agilidade em comparação com as experiências tradicionais de UI/UX.
